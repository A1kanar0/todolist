# 🚀 Task & Note Management System

> ⚠️ **Увага:** Проєкт наразі перебуває в стадії активної розробки (Work In Progress). Функціонал може змінюватися, розширюватися та оптимізуватися.

Комплексний веб-додаток для ефективного управління завданнями (з підтримкою ієрархії підзавдань) та ведення детальних нотаток із розширеним форматуванням. Проєкт побудований на сучасній мікросервісній архітектурі з використанням **React**, **GraphQL** та **ASP.NET Core**.

## ✨ Основний функціонал

### 📝 Нотатки (Notes)
* **Кастомний WYSIWYG редактор:** підтримка форматування тексту (жирний, курсив, підкреслений), додавання посилань та зображень. Відстеження активного форматування.
* **Глобальні теги:** створення тегів із кастомними кольорами, прив'язка до нотаток, безпечне глобальне видалення тегів.
* **Розумна фільтрація:** можливість шукати нотатки за текстом, фільтрувати за автором та обирати одразу декілька тегів (мультиселект).
* **Сучасний рендер:** безпечне відображення збереженого HTML із використанням `tailwindcss/typography` (`prose`).

### ✅ Завдання (Tasks)
* **Деревоподібна структура:** підтримка головних тасок та вкладених підзавдань (Tree-based structure).
* **Керування статусами:** To Do, In Progress, Done.
* **Деталізація:** встановлення дедлайнів, прив'язка до категорій та призначення виконавців (Executors).
* **Фільтрація:** пошук за назвою, категоріями, виконавцями та статусом.

## 🛠 Технологічний стек

**Бекенд:**
* **ASP.NET Core (Web API)** — основа серверної частини.
* **HotChocolate** — GraphQL бібліотека для .NET.
* **Dapper** — мікро-ORM для швидкої роботи з базою даних.
* **DbUp** — бібліотека для управління міграціями.
* **PostgreSQL (alpine)** — реляційна база даних (легка alpine-версія).

**Фронтенд:**
* **React** — бібліотека для побудови інтерфейсів.
* **TypeScript** — сувора типізація для безпечного коду.
* **Vite** — інструмент для збірки фронтенду.
* **Zustand** — стейт-менеджер (`useNoteStore`, `useTaskStore`).
* **Tailwind CSS** — стилізація UI.
* **React Router v6** — маршрутизація.

**Інфраструктура:**
* **Docker** & **Docker Compose** — контейнеризація всього середовища.

## 🚀 Як запустити проєкт

### Варіант 1: Запуск через Docker (Рекомендовано)

Найшвидший спосіб підняти базу даних, бекенд та фронтенд однією командою.

1. Переконайтеся, що у вас встановлений Docker Desktop.
2. Відкрийте термінал у кореневій папці проєкту (де лежить `docker-compose.yml`).
3. Виконайте команду:
   ```bash
   docker-compose up -d --build
   ```
4. Додаток буде доступний за адресами:
   * **Frontend:** http://localhost:5173
   * **Backend (GraphQL):** http://localhost:5000/graphql/

*Щоб зупинити контейнери, виконайте:* `docker-compose down`

### Варіант 2: Локальний запуск (для розробки)

Якщо вам потрібно працювати над кодом без кешування Docker (наприклад, при встановленні нових npm-пакетів).

**1. Запуск БД та Backend:**
* Переконайтеся, що запущено PostgreSQL (можна запустити лише БД через Docker).
* Відкрийте бекенд-частину проєкту у вашій IDE (Visual Studio / Rider) та запустіть Web API.

**2. Запуск Frontend:**
* Відкрийте новий термінал і перейдіть у папку фронтенду:
  ```bash
  cd src/frontend
  ```
* Встановіть залежності:
  ```bash
  npm install
  ```
* Запустіть сервер розробки Vite:
  ```bash
  npm run dev
  ```
* Відкрийте у браузері згенероване посилання (зазвичай `http://localhost:5173`).

## 📂 Структура проєкту (Frontend)

```text
src/
├── components/       # Перевикористовувані UI компоненти
│   ├── notes/        # Компоненти нотаток (NoteCard, NoteDetails)
│   ├── tasks/        # Компоненти завдань (TaskItem, TaskDetails)
│   └── ui/           # Спільні UI елементи (Кнопки, SearchInput, TextEditor)
├── pages/            # Сторінки (Home, Notes, Tasks)
├── store/            # Zustand стейт-менеджери (useNoteStore, useTaskStore)
├── utils/            # Допоміжні функції (напр. API fetchGraphQL)
└── App.tsx           # Головний компонент із роутингом
```

## 🤝 Внесок та розробка (Git Workflow)

1. Створіть нову гілку від `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. Перед злиттям з мейном, підтягніть свіжі зміни:
